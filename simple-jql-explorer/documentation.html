Getting Started

1. Install the App
Install Simple JQL Explorer for Jira from the Atlassian Marketplace onto your Jira Cloud instance.
2. Open the App
Navigate to it from your Jira project (or the surface it installs into).
3. Start Using It
The app builds its views from your live Jira data, no extra setup required.
