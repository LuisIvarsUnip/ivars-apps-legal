Privacy Policy

Project Cost Tracker - Budget & Worklog Costs for Jira • Last updated: 2026-10-07

This Privacy Policy describes how Ivars Apps (Luis Ivars Unipessoal Lda) ("we", "us", "our") handles data in connection with the Project Cost Tracker - Budget & Worklog Costs for Jira application ("the App"), available on the Atlassian Marketplace.

1. What Data the App Accesses

The App reads the following data from your Atlassian instance to provide its functionality:

  • Jira issues returned by your searches (summary, status, priority, assignee, labels, due dates, issue type)
  • JQL query results you run in the app
  • Jira project metadata (project key, name)
  • Current user identity (display name), used for the app UI
  • App configuration you save (for example saved queries, column layouts or per-project settings), stored in Atlassian Forge Storage (KVS)

2. How Data is Processed

All data processing occurs entirely within the Atlassian Forge platform. The App:

  • Runs in Atlassian's sandboxed Forge environment (server-side)
  • Renders its UI in a sandboxed iframe (client-side)
  • Does NOT transmit any data to external servers
  • Does NOT use third-party analytics, tracking, or advertising services
  • Does NOT collect, store, or process user credentials or API tokens
  • Keeps aggregated, anonymous usage counters through Atlassian's Forge metrics (for example the number of active users per day); these counters contain no personal data and never leave Atlassian

3. Data Storage

The App stores the following in Atlassian Forge Storage (KVS), which is hosted and encrypted by Atlassian within your tenant's infrastructure:

  • App configuration you save (for example saved queries, column layouts or per-project settings)
  • A per-user usage record that operates the App's in-app review prompt and measures adoption: your Atlassian account ID together with action counts, the dates of use and the prompt's state (shown, snoozed, reviewed). It holds no names, email addresses or issue content.
  • A short-lived cache of query results (at most 10 minutes) so repeated views load faster. Cache entries are keyed to the requesting user, are never shared between users and expire automatically.

Beyond the items above, no issue data or report content is stored: the data used to render the App's views is read live from Jira on each request.

4. Data Sharing

We do NOT share, sell, rent, or disclose any of your data to third parties. The App has no sub-processors.

5. Data Retention and Deletion

When the App is uninstalled from your Atlassian site, data stored in Forge Storage is soft deleted and retained by Atlassian according to Forge-hosted storage lifecycle policies before permanent deletion.

Forge-hosted storage is not automatically restored on reinstallation. Where Atlassian's recovery window applies, data may be recoverable for a limited period through Atlassian support workflows.

6. Data Residency

The App runs on Atlassian Forge infrastructure and follows your Atlassian tenant's data residency configuration. We do not independently store or transfer data to any specific geographic region.

7. GDPR Compliance

We act as a Data Processor under the General Data Protection Regulation (GDPR). Atlassian acts as the infrastructure provider. Your organization remains the Data Controller.

  • The App processes personal data only as necessary to provide its functionality (display names, assignee information)
  • The only personal data the App stores is the per-user usage record described in section 3 (your Atlassian account ID with usage counts and dates); it is deleted together with the App
  • Data subject access requests (DSAR) should be directed to your Atlassian site administrator; uninstalling the App deletes all data it stored

8. Security

  • All data at rest in Forge Storage is encrypted by Atlassian
  • All communication occurs over HTTPS
  • The App reads Jira data with the invoking user's own permissions via the Atlassian Forge platform, ensuring proper permission scoping
  • No credentials or secrets are stored in the App
  • The App requests only the minimum Forge scopes necessary for functionality

9. Children's Privacy

The App is designed for business use within Atlassian products and is not intended for use by children under 16.

10. Changes to This Policy

We may update this Privacy Policy from time to time. Changes will be reflected by updating the "Last updated" date at the top of this page. Continued use of the App after changes constitutes acceptance.
