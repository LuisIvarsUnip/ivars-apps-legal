Project Intelligence Hub for Jira

User Guide & Documentation • Version 2.5.0

Project Intelligence Hub for Jira turns live Jira project data into stakeholder-ready reports in one click. Generate professional status reports, release notes, and executive dashboards directly from your Jira project — then export to PDF, push to Confluence, or copy to the clipboard.

How It Works

The app runs inside Jira as a project-level page. Open it from any project, pick a report template, and the app builds the report from your live Jira data — issues, sprints, epics, versions, and team activity. You can review and edit the report before exporting.

Getting Started

1 Install the App
Install Project Intelligence Hub for Jira from the Atlassian Marketplace onto your Jira Cloud instance.
2 Open the App
Navigate to any Jira project and click "Project Intelligence Hub" in the project navigation.
3 Pick a Report Template
Choose one of the seven templates. Most generate instantly; Release Notes asks you to pick a project version first.
4 Review and Edit
The report is built from live Jira data. Edit summary fields, status messages, and notes inline before sharing.
5 Export
Export to PDF, push directly to Confluence, or copy formatted HTML to the clipboard.

Key Features

Automatic RAG Status

Reports that include a health indicator calculate it automatically from your Jira data:

  • On Track — Progressing as planned
  • At Risk — Needs attention, potential delays
  • Off Track — Action required, significant issues

The status is derived from overdue issues, blockers, and sprint progress. You can override it manually at any time.

Story-Point Velocity

The app detects your instance's Story Points custom field automatically and uses it to calculate velocity in the Weekly Status, Sprint Retrospective and other reports. If your project does not use story points, velocity falls back to issue counts.

Export Options

  • PDF — A polished, print-ready document for email or archiving
  • Confluence — Push the report directly to a Confluence space and page of your choice
  • Clipboard (HTML) — Copy formatted content to paste into email, docs, or chat

Project Settings

Use the Settings panel to set the client name, project manager, and a custom footer that appears on exported reports.

Frequently Asked Questions

Which Jira project types are supported?

Both company-managed and team-managed projects on Jira Cloud. Sprint-based reports require a Scrum or Kanban board.

Where do story points come from?

The app scans your Jira field registry for the "Story Points" or "Story Point Estimate" field and uses it automatically. No manual configuration is needed.

Does the app store my Jira data?

No. Reports are generated on demand from live Jira data. The app only stores your project settings (client name, PM, footer) and anonymous usage counters in Atlassian's Forge storage.

Why does a report show zero velocity?

Either the project has no story points on its issues, or no "Story Points" field exists on the instance. Velocity then falls back to issue counts where applicable.

Can I push the same report to Confluence twice?

Yes. If a page with the same title already exists, the app appends a timestamp so nothing is overwritten.

Is it secure?

Yes. The app is built on Atlassian Forge and runs entirely within Atlassian's infrastructure. No data is sent to external servers.
